# Inventory Management — UI prototype

Same codebase and UI kit as the CodeIT training portal (React 19 + Vite + Tailwind 4 +
react-router), re-coloured to the Indigo·Dusk palette. UI only — all data is sample data
in `src/data/mockData.js`; nothing is saved.

```bash
npm install
npm run dev
```

Sign in with any email and password.

To change the colours, edit the brand ramp and the `:root` tokens in `src/index.css` —
no component writes a brand hex.
